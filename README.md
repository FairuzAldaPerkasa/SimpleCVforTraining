Proyek ini adalah sebuah Curriculum Vitae (CV) digital dalam bentuk halaman web tunggal. Dibuat sebagai tugas mata kuliah Pemrograman Website, halaman ini menampilkan informasi pribadi dan profesional dengan desain dua kolom yang responsif dan beberapa fitur interaktif menggunakan JavaScript.

---

## ✨ Fitur Utama

-   **🎨 Desain Dua Kolom:** Tampilan CV dibagi menjadi dua bagian:
    -   **Kolom Kiri:** Berisi informasi kontak, profil singkat, dan ringkasan kemampuan (skills) dengan progress bar visual.
    -   **Kolom Kanan:** Menampilkan bagian-bagian detail seperti "Tentangku", "Pengalaman Organisasi", "Riwayat Pendidikan", dan "Bidang Minat".
-   **📱 Desain Responsif:** Tampilan website dapat beradaptasi dengan baik di berbagai ukuran layar, mulai dari desktop hingga perangkat mobile.
-   **📜 Accordion Interaktif:** Bagian-bagian di kolom kanan (Tentangku, Pengalaman, dll.) berfungsi sebagai *accordion* yang dapat dibuka-tutup dengan mengklik judulnya, membuat navigasi lebih ringkas.
-   **🖱️ Tombol Interaktif:**
    -   **Tampilkan NIM:** Tombol untuk menampilkan Nomor Induk Mahasiswa (NIM) secara dinamis.
    -   **Tampilkan Alamat:** Tombol yang memunculkan *alert* berisi informasi alamat lengkap.
    -   **Cetak Halaman:** Tombol "Print" yang memungkinkan pengunjung untuk mencetak halaman CV langsung dari browser.
-   **📊 Visualisasi Kemampuan:** Keterampilan pemrograman (JavaScript, C++, HTML/CSS) ditampilkan menggunakan *progress bar* untuk memberikan representasi visual tingkat kemahiran.

## 🛠️ Teknologi yang Digunakan

-   **Struktur:** **HTML5**
-   **Styling:** **CSS3** (termasuk Flexbox/Grid dan media queries untuk responsivitas)
-   **Interaktivitas:** **Vanilla JavaScript**

## 📂 Susunan Proyek

Proyek ini memiliki struktur yang sederhana dan terdiri dari file-file berikut:

/websitefairuz ├── cv.html # File utama yang berisi struktur konten CV. ├── cv.css # File styling untuk mengatur tampilan dan layout. ├── cv.js # File JavaScript untuk semua fungsionalitas interaktif. ├── profil.jpg # Foto profil yang ditampilkan di CV. └── Header.jpg # Gambar header yang digunakan di bagian "Tentangku".


## 🚀 Prasyarat & Penggunaan

Tidak ada prasyarat khusus untuk menjalankan proyek ini selain browser web modern.

1.  **Clone atau Unduh Repository:**
    ```bash
    git clone [https://github.com/fairuzaldaperkasa/websitefairuz.git](https://github.com/fairuzaldaperkasa/websitefairuz.git)
    ```
2.  **Buka File:**
    -   Navigasi ke direktori tempat Anda menyimpan proyek.
    -   Buka file `cv.html` menggunakan browser pilihan Anda (misalnya, Google Chrome, Mozilla Firefox, atau Microsoft Edge).

### Contoh Penggunaan Fitur
-   **Melihat Detail:** Klik pada judul-judul di sisi kanan seperti "TENTANGKU", "PENGALAMAN ORGANISASI", atau "RIWAYAT PENDIDIKAN" untuk membuka dan menutup detailnya.
-   **Melihat NIM:** Klik tombol di bawah "Contact Info" yang bertuliskan "NIM :". NIM akan muncul di sebelahnya.
-   **Melihat Alamat:** Klik tombol "Klik disini untuk alamat" untuk melihat alamat lengkap dalam sebuah notifikasi *pop-up*.
-   **Mencetak CV:** Klik tombol "Print" di bagian bawah halaman untuk membuka dialog cetak browser.
